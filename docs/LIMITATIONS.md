# Limitations

- The public repository does not redistribute the competition dataset or trained weights.
- The image-to-BEV branch is a simplified educational baseline, not a full LSS
  implementation.
- No new metric was produced during the 2026 portfolio cleanup.
- Historical predictions were generated with multiple experimental settings and should
  not be compared without a fresh unified evaluation.
- The detector targets only Car, Cyclist, and Truck.
- The code is optimized for reproducing the project structure and reasoning, not for
  real-time deployment.
- Sensor calibration, coordinate conventions, thresholds, and data access must be
  verified before adapting the code to another dataset.
